¿Cómo registrar el ajuste?
Merma

Para retirar productos vencidos, dañados o perdidos, escribe la cantidad a descontar como un número positivo.

Ejemplo: retirar 2 cajas → digita 2.
Ajuste de stock

Para corregir un conteo o un error de digitación, usa un valor positivo para aumentar el stock y uno negativo para disminuirlo.

Ejemplos: aumentar 3 unidades → 3 / descontar 2 unidades → -2.
